## قابلیت‌ها

- اضافه کردن کار جدید (Todo)
- انجام شده / انجام نشده کردن کارها
- حذف کار
- فیلتر کردن کارها (All / Active / Completed)
- ذخیره اطلاعات با localStorage
- نمایش تعداد کارهای انجام‌شده
- حذف همه کارهای انجام‌شده

---

## نحوه کار پروژه

### اضافه کردن Todo
کاربر متن مورد نظر را داخل input وارد می‌کند و با کلیک روی دکمه Add،  
یک todo جدید ساخته می‌شود.  
هر todo به صورت یک آبجکت شامل id، متن و وضعیت انجام‌شدن ذخیره می‌شود.

---

### انجام شدن کار (Done)
برای هر todo یک دکمه Done وجود دارد.  
با کلیک روی این دکمه، وضعیت completed آن todo تغییر می‌کند.  
برای این کار از متد `map` استفاده شده است.

در صورتی که کار انجام شده باشد، یک کلاس CSS به آن اضافه می‌شود تا متن خط‌خورده نمایش داده شود.

---

### فیلتر کردن Todoها
سه دکمه All، Active و Completed برای فیلتر کردن کارها وجود دارد.  
بسته به دکمه انتخاب‌شده، فقط کارهای مربوطه نمایش داده می‌شوند.

---

### ذخیره اطلاعات
برای ذخیره اطلاعات از `localStorage` استفاده شده است.  
آرایه todoها با استفاده از `JSON.stringify` ذخیره می‌شود  
و هنگام بارگذاری صفحه دوباره با `JSON.parse` خوانده می‌شود.

به این شکل بعد از رفرش صفحه، اطلاعات از بین نمی‌روند.

---

###  اضافی 
- نمایش تعداد کارهای انجام‌شده با استفاده از `reduce`
- دکمه حذف همه کارهای انجام‌شده (Clear Completed)
